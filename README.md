# 최저가 레이더

검색어 한 번으로 쿠팡·네이버·11번가·G마켓·옥션·알리·테무·무신사를 열고,
네이버쇼핑에 올라온 여러 판매처 가격을 한 화면에 모아 보는 개인용 웹앱입니다.

앱 주소: https://dweom0720-alt.github.io/lowradar/

> 2026년 7월 31일 네이버 쇼핑 검색 API가 종료되어, v2부터는 네이버쇼핑 화면이 쓰는 공개 데이터를
> 중계서버가 읽어 옵니다. **네이버 API 키는 필요 없습니다.** 비공식 방식이라 네이버가 형식을 바꾸거나
> 막으면 최저가 목록만 멈추고, 사이트 바로가기·찜·가격 기록은 그대로 동작합니다.

---

## 중계서버 만들기 (Cloudflare Worker, 무료, 약 10분)

1. https://dash.cloudflare.com/sign-up 무료 가입 → 메일 인증
2. 왼쪽 **Compute (Workers) → Workers & Pages → Create → Start with Hello World!**
3. 이름 `shop-proxy` → **Deploy** (처음이면 계정 주소 이름도 정함, 예: `dweom`)
4. **Edit code** → 기존 코드 전부 지우기 →
   https://github.com/dweom0720-alt/lowradar/blob/main/worker.js 의 **복사 아이콘**으로 복사해 붙여넣기 → **Deploy**
5. 확인: 브라우저에서 `https://shop-proxy.<계정이름>.workers.dev/?query=생수` 열기
   - `"items":[{"title":...` 처럼 상품이 보이면 성공
   - `blocked` 가 보이면 네이버가 중계서버 접속을 막은 것 → 아래 "막혔을 때" 참고

## 앱에 연결

1. 앱 주소 열기 → **설정** 탭 → 중계서버 주소에 `https://shop-proxy.<계정이름>.workers.dev` 입력
2. **저장하고 연결 확인** → "✓ 연결됐습니다"
3. 폴드 크롬 메뉴(⋮) → **홈 화면에 추가 → 설치**
   → 쿠팡·네이버 앱에서 상품을 **공유 → 최저가 레이더** 하면 바로 검색

## 기능

| 기능 | 쓰는 법 |
|---|---|
| 사이트별 바로 열기 | 검색 후 사이트 버튼 → 그 사이트 검색 결과 |
| 최저가 목록 | 정렬(정확도·낮은가격·높은가격·리뷰많은), 최저가 노란 표시, 할인 전 가격 표시 |
| 찜 + 가격 기록 | ♡ 누르면 그날 가격 저장, **가격 새로고침**마다 날짜별 기록·그래프 |
| 목표가 | 찜 카드에 목표가 입력 → 그 이하가 되면 "목표가 도달" |
| 자동 갱신 | 앱을 하루 처음 열 때 찜 가격 자동 확인 |
| 직접 찜 | 목록에 없는 상품은 이름·가격 직접 입력 |
| 최근 검색·자주 사는 품목 | 검색어 칩, ☆ 즐겨찾기 |
| 사이트 설정 | 켜기·끄기·순서, 광고 상품 빼기 |
| 백업 | 폰↔탭 옮길 때 백업 파일 저장·불러오기 |

## 막혔을 때

- 앱에 "네이버가 요청을 거절했습니다"가 나오면 네이버가 중계서버를 막은 것입니다. 반복 시도로 우회하지 말고 Claude에게 알려 주세요.
- 가격은 배송비 별도, 조회 시점 기준 참고값입니다.
- 쿠팡 일부·알리·테무는 네이버쇼핑에 없을 수 있어 사이트 버튼으로 함께 확인하세요.
